# Ecstatic  Aesthetics Portfolio Website

## Description
Ecstatic  Aesthetics is the personal portfolio website of **Bianca L. Beltran**, a passionate graphic designer. The website showcases Bianca’s creative projects, professional experience, and skills, while providing an easy way for clients and collaborators to get in touch.  

This responsive and visually engaging site is designed to highlight branding, illustration, and web design work while ensuring a user-friendly experience.

---

## Features
- **Home Section**  
  Introduces Bianca with a short bio and headshot.

- **About Section**  
  Detailed overview of Bianca’s creative experience, education, skills, programs, and language proficiency.  
  - Includes downloadable resume in PDF format.

- **Portfolio Section**  
  Showcases selected projects with images and descriptions.

- **Contact Section**  
  Contact form with fields for Name, Email, and Message.  
  - Form includes input validation (`required` and `minlength`) and links to email submission.  

- **Navigation**  
  Sticky navigation bar for easy access to all sections of the site.  

- **Footer**  
  Social media link (Facebook) and copyright information.

---

## Technologies Used
- HTML5  
- CSS3  
- Adobe Dreamweaver (for site design)  
- Images and graphics created using Adobe Creative Suite and Procreate

---

## Usage
1. Clone or download this repository.
2. Open `index.html` in a web browser to view the site.
3. Click on the navigation links to explore different sections.
4. Use the contact form to send an email (requires a configured local email client).
